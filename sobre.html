O porque deste app?

Esta aplicação foi criada no âmbito da disciplina de Sistemas Informáticos para complementar a PAP do curso de Multimédia, permitindo apresentar o projeto de animação de forma digital, organizada e interativa.

O que é isto

É uma aplicação/web app desenvolvida com HTML, CSS e JavaScript para apresentar a animação, o storyboard, as vozes e outras etapas do desenvolvimento do projeto.

Para que isto serve

Esta aplicação serve para mostrar todo o processo de criação da PAP, facilitando a navegação pelos conteúdos e permitindo uma apresentação mais moderna e acessível do projeto de animação.
